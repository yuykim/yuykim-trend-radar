# Fieldnote — 기술 트렌드 레이더 프로토타입

외부 의존성·네트워크·빌드가 없는 한국어 정적 프로토타입입니다. 모든 수치, 논문 요약, 기술 관계, 기업과 주가는 더미이며 실제 예측이 아닙니다. 실제 기업 및 논문 출처로 연결하지 않습니다.

## 실행

`prototype/index.html`을 브라우저에서 직접 열 수 있습니다(`file://`). 또는 프로젝트 루트에서 다음 명령으로 실행하세요.

```powershell
python -m http.server 8000 --directory prototype
```

브라우저에서 `http://localhost:8000`에 접속합니다. 종료는 `Ctrl+C`입니다. 현재 확인용 서버는 `http://127.0.0.1:5173`에서 실행 중입니다.

## 살펴볼 기능

- 오늘의 레이더: 8개 기술, 4개 영역, 키워드 검색, 분류 필터, 검색 결과가 없는 상태.
- 상세: 카드나 그래프 노드 클릭. 설명, 접근의 차이, 논문·커뮤니티 별도 추이, 예시 논문, 코드·모델 공개 상태, 불확실성, 독립 기관 수, 공개일·포착일, 접을 수 있는 기업·주가 정보.
- 관심 목록: ☆ 또는 상세의 관심 저장 버튼. 같은 브라우저·주소에서 새로고침 후 유지. 브라우저가 localStorage를 차단하면 현재 화면에서만 유지하며 저장 동작 시 안내합니다. `file://`의 저장 동작은 브라우저 설정에 따라 다릅니다.
- 기술 관계도: 노드 클릭 또는 Tab → Enter/Space. +/− 및 휠 확대·축소, 초기화, 빈 배경 드래그 이동. 120% 이상에서 가상 기업 표시. 기술·기업·주가 상관 레이어. 필터와 검색은 그래프에도 적용됩니다.
- 상세는 기본 HTML dialog로 키보드 포커스를 제한하고 Escape/닫기 버튼으로 닫습니다. 닫은 뒤 열었던 요소로 포커스를 복원하며, 요소가 사라진 경우 현재 메뉴로 이동합니다.
- 모바일 가로 메뉴·한 열 카드, focus-visible, prefers-reduced-motion 대응.

## 범위와 제한

기간은 최근 30일로 고정입니다. 상세 차트는 30일을 10개 구간으로 나눈 예시 건수이며, 카드의 논문·커뮤니티 수는 30일 합계입니다. 그래프 관계의 방향은 화살표를 따릅니다. 기업 연결에는 방향이나 소유 관계를 부여하지 않았습니다. 수익률 상관은 최근 120거래일을 가정한 고정 예시 값입니다.

backend, 데이터 수집, 실제 논문 검증, 로그인, 실제 시세, 예측 기능은 포함하지 않습니다. 네이티브 dialog를 지원하는 최신 브라우저를 사용하세요. JS 문법, HTTP 응답, 브라우저에서 상세·검색·관심 저장·그래프 확대·레이어 동작과 390px 화면의 가로 넘침 여부를 확인했습니다. 자동 스크린샷은 브라우저 도구의 화면 캡처 제한으로 확보하지 못했습니다.
