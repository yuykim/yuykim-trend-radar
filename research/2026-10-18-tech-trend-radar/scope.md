# Scope: 기술 트렌드 레이더의 가치 검증

## 핵심 질문
- Q1. 학회 논문(+arXiv)과 커뮤니티(Reddit, X, Threads) 신호로 **현재 각광받는 기술**을 신뢰성 있게 파악할 수 있는가?
- Q2. 같은 데이터로 **새로 등장하는 기술(emerging topic)** 을 조기에 탐지할 수 있는가? 얼마나 일찍, 얼마나 정확하게?
- Q3. **미래에 뜰 기술**을 예측하는 것이 실증적으로 가능한가? 어떤 신호(인용, 저자·기관, 소셜 언급, 코드 공개 등)가 예측력이 있는가?
- Q4. 소셜/커뮤니티 신호는 논문 신호 대비 **선행성**이나 추가 정보를 주는가? 잡음·hype 위험은?
- Q5. 기술-기업 연결(knowledge graph)과 주가 co-movement 표시는 **참고 정보로서** 의미가 있는가? (주가 예측은 목표가 아님)
- Q6. 가치를 높이려면 어떤 요소를 추가해야 하는가?

## 우리 조건
- 사용자: 개인 1명 (Robot Learning / World Model / VLA 연구 관심자). 목적은 **기술 트렌드 파악과 신기술 조기 인지**이고, 투자 판단은 부차적.
- 초기 도메인: Physical AI (Robotics, VLA, World Model, JEPA 계열 등)로 좁게 시작.
- 데이터: OpenReview, OpenAlex, arXiv 등 무료 API + Reddit / X / Threads (API 접근 제약 있음) + 주가(토스증권 Open API, 참고용).
- 화면: 요약 대시보드(A) → 기술 상세(B), Obsidian식 graph view (축소=기술, 확대=기업, 기술 간·기업 간 연결).
- 갱신 주기: 매일 아침 확인.
- 자원: 개인 프로젝트, 고가 유료 데이터 없음.

## 제외
- 주가 예측·자동매매 신호 생성.
